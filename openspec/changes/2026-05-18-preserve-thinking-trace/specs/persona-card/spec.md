# persona-card —— 增量

本文件是对 [openspec/specs/persona-card/spec.md](openspec/specs/persona-card/spec.md)
的增量，仅列出本 change 新增的 Requirement。归档时会并入主 spec。

## ADDED Requirements

### Requirement: 终态保留 agent 过程档案
最终人格卡渲染后，系统 SHALL 在同一页面上保留本次运行的 agent 过程档案
——「浏览器内解析 → 概览读取 → 聚类点评 → agent 深挖叙述与抓取状态 →
合成预告」——使整页成为一份可从上到下回溯的运行记录。

#### Scenario: 生成结束后回看过程
- **WHEN** 一次 agent 运行成功完成且人格卡已渲染
- **THEN** 页面同时展示过程档案与人格卡
- **AND** 过程档案中的步骤指示器全部呈现「已完成」静态形态，不再出现
  「正在进行」或闪烁光标
- **AND** 此前流式累积的聚类点评、深挖叙述、抓取目标列表、合成预告
  在终态下原样可读

#### Scenario: 导出与分享仅承载卡片
- **WHEN** 用户在终态点击「保存为图片」或「复制分享链接」
- **THEN** 导出的图片仅包含人格卡本体，不包含过程档案
- **AND** 通过分享链接 `/c/:id` 打开的页面按派生画像渲染卡片，与过程
  档案无关

#### Scenario: 换风格重新生成后保留原过程档案
- **WHEN** 用户在终态点击某个风格按钮触发重合成
- **THEN** 系统替换人格卡为新风格变体
- **AND** 过程档案保持上一次 agent 运行的原貌不变（深挖未重跑，过程
  档案在事实上仍准确）
- **AND** 系统不为本次重合成伪造新的合成预告思考文本

#### Scenario: 重新拖入新文件清空过程档案
- **WHEN** 用户在终态把另一份书签 HTML 文件拖入上传区
- **THEN** 系统清空旧过程档案与旧卡片
- **AND** 重新开始展示新一次运行的过程档案
